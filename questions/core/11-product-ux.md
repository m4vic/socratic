# Core Product and Developer Experience

1. What is the shortest successful user journey?
2. What happens with no data, slow work, success, failure, and retry?
3. What is the likely user mistake, and can it be prevented or reversed?
4. Are defaults, costs, data collection, and irreversible actions clear?
5. Can a new user succeed without undocumented knowledge?
6. For a CLI, are help, exit codes, human output, and machine output reliable?

Verify the primary journey, every error state, slow behavior, recovery, and first-use onboarding.
