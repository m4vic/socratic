# Core Requirements and Scope

Resolve these for every build:

1. What problem and measurable outcome define success?
2. Is this disposable, a prototype, maintained, or production-critical?
3. Who uses it, at what scale, and what existing system must it coexist with?
4. What is explicitly out of scope for this iteration?
5. Which constraints, contracts, and downstream consumers cannot change?
6. Which high-risk assumption should be tested first, and what is the cheapest reliable way to test it?

Verify that the result solves the real problem, includes every must-have, excludes declared non-goals, and can be understood from its documentation.
